## LaboroTomato Benchmark

The LaboroTomato dataset is not included in this repository.

To run benchmarking on LaboroTomato:
1. Download the dataset from the official source.
2. Place the dataset under:
   benchmarks/datasets/laborotomato/
   ├── JPEGImages
   └── Annotations
3. Run the dataset conversion and evaluation scripts.

This design keeps the repository lightweight and ensures licensing compliance.
